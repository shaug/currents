# Synthetic payroll relationship input

Input for the explicit synthetic-relationships/1 profile and CUR015 qualification.
This fixture is not itself acceptance evidence or a production import profile.
All identifiers and amounts are synthetic.
The five source facets remain distinct. An explicit owner account/policy choice
is required for withholding, retirement, HSA and net destination; the parser
cannot select them. The net-only control must not fabricate gross or deductions.
