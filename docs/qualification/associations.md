# CUR015 explicit source-to-economic associations

This is a synthetic-only qualification surface, not household readiness or a
production provider. `cargo xtask ticket CUR-015` executes the exact registered
source, domain, wire and encrypted Service assertion inventories. A registration
is not a passing candidate: use the exact-head platform reports and review.

The explicit relationship-source v1 JSON profile retains bounded original bytes,
capture and receipt times, typed facets, source revision and predecessor identity.
Arrival order, provider IDs, descriptions, missing rows and tombstones do not
create financial authority. Conflicting or disconnected revisions remain retained
and cannot be selected by arrival order. Replay verifies typed captured rows
against the original retained bytes before activating the domain projection.

Owner-approved complete association revisions bind exact captured facets to
immutable dated legs. Additive capacities cannot multiply a source amount;
corroborating evidence cannot multiply a leg. Transfer principal uses a declared
Clearing account; separately evidenced fees use ExpenseFlow. Payroll preserves
gross, withholding, retirement, HSA and net facets. Net-only evidence is not a
complete payroll interpretation. Withholding requires the explicit ExpenseFlow
or TaxPrepayment choice; no tax treatment is inferred.

Initial multi-date recognition and complete same-family remaps are single bounded
C04 atomic closures. Remaps retire every prior current original and introduce
fresh legs/recognitions, preserving all historical evidence. Declared retirements
must exactly equal frozen native reversals. Partial failure publishes neither
half. The duplicate route selects an explicit survivor among existing C08 posted
single-leg recognitions and reverses every redundant original. It does not offer
arbitrary cross-association or accounting-segment surgery (CUR016).

The encrypted Service tests cover all six separately committed transfer arrival
orders, original dates and fee separation; both explicit payroll tax choices;
source-amount remap cancellation/reopen/identical retry; parser reparse without
duplicate adoption; N-way survivor; explicit pending expiry; and stable reconnect
aliases. Native replay must reproduce the exact head for each history. Different
arrival histories compare exact dated economic postings, not authenticated native
heads, because C05 also binds each distinct prior domain history.

An explicit pending expiry is nonmonetary. Incomplete feeds and source tombstones
never expire pending evidence or refund recognized money. Source reconnect is an
explicit alias on the same account, not a new account or opening. The test-only
trusted planner is not a production host or a new general query implementation.
Legacy import/command encodings remain unchanged; complete new DTOs are versioned
and reject missing or unknown fields.
