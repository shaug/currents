## Why

Implement local stdio MCP wrapper with explicit versioned tool schemas for owner-scoped redacted queries and proposal submission.

## Scope

Implement local stdio MCP wrapper with explicit versioned tool schemas for owner-scoped redacted queries and proposal submission. Default no dataset access until owner names external agent/fields/accounts; no raw evidence, credentials, exports, maintenance, scope changes, shell or arbitrary paths. Tool can propose financial action but cannot approve its own proposal. No remote AI/data relay.
