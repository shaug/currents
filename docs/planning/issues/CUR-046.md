## Why

Implement narrow iOS UI/capture queue with device-protected encrypted storage, source permission/availability checks and owner-selected file imports.

## Scope

Implement narrow iOS UI/capture queue with device-protected encrypted storage, source permission/availability checks and owner-selected file imports. FinanceKit adapter enabled only after passed gate; show captured/queued/acknowledged/gap states and owner-initiated transfer. No mobile accounting edits, journal, automatic cloud recipient or unsupported background freshness promise. Implement and test capture synthetically without entitlement/credential dependency. FinanceKit stays disabled until CUR-044 route gate, and no actual account capture occurs until separate CUR-057 after private activation.
