## Why

With separately approved secure signing setup, build nested app/XPC/helper/CLI artifacts, least-privilege entitlements/hardened runtime, explicit Developer ID signing, notarytool and stapling.

## Scope

With separately approved secure signing setup, build nested app/XPC/helper/CLI artifacts, least-privilege entitlements/hardened runtime, explicit Developer ID signing, notarytool and stapling. Do not use --deep as substitute. Verify final linked crypto identity/signatures/Gatekeeper, clean supported OS install/offline launch, upgrade/migration interruption/recovery and native machine ABI. No certificates/tokens generated or persistent CI access expanded without required consent. Separately qualify the actual iOS route selected in CUR-044: provisioning profile, FinanceKit entitlement, signing identity, protected storage, real-device install/update and authorized distribution method. Mac Developer ID/notarization does not qualify iOS. Any App Store/TestFlight submission, persistent credentials or agreement requires separate approval; missing route remains blocked.
