## Why

Verify current FinanceKit managed entitlement, organization developer account, distribution eligibility and actual Apple Card account/history/background timeliness through an authorized path.

## Scope

Verify current FinanceKit managed entitlement, organization developer account, distribution eligibility and iOS 18.0 API route from official sources and any separately authorized developer entitlement steps. This route-only gate does not perform an actual financial-account probe. CUR-046 implements protected capture synthetically; CUR-057 later verifies real Apple Card coverage after security/private setup. File statements remain a proposed owner-accepted compromise, not assumed automatic parity.
