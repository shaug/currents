## Why

Create manually gated release pipeline from tested approved tag/commit.

## Scope

Create manually gated release pipeline from tested approved tag/commit. Human-reviewed changelog categories/features/fixes/security and compatibility/backup/migration/privacy/limitations notes; git-cliff drafts not final policy. Produce unsigned Mac payload, Mac CLI, Linux verifier/source archive, checksums, full native+Rust+Swift SBOM/licenses, build manifests and provenance. Separate ordinary CI from signing job, minimum job tokens, pinned actions, offline source-vendored rebuild and unsigned reproducibility comparison. No crate/Homebrew/container/update publication.
