## Why

Implement production owner-only Keychain and LocalAuthentication adapters, separate dataset/recovery/connector/ingress secrets and OS CSPRNG.

## Scope

Implement production owner-only Keychain and LocalAuthentication adapters, separate dataset/recovery/connector/ingress secrets and OS CSPRNG. Lock on OS session lock/explicit action/15min client inactivity; stop admission, revoke grants, cancel/drain writer, await all closes then clear best effort. Scheduled refresh never unlocks. Protect paths/files and reject symlink escapes; FileVault recommendation not encryption substitute. This implementation ticket proves synthetic key/lock behavior; actual production signed identity/Keychain/LocalAuthentication qualification is CUR-056, not a hidden prerequisite to complete CUR-032.
