## Scope

Implement due-on-unlock/changed-data24 h encrypted backups, all-successful-generation retention and protection health. Independent destination/offline recovery key and restore ceremony required before live acquisition. Optional device recovery-key copy requires explicit consent; without it request secure local key entry when due. Seven-day uncommitted/transient cleanup only. Disconnect removes credentials/stops fetch preserving authority; whole-dataset deletion distinct fresh confirmation enumerates copies/keys/unreachable targets.
