## Scope

After the protected iOS queue, transfer bridge, signed Mac host and independent recovery setup pass, perform only separately authorized actual FinanceKit Apple Card account checks. Verify transactions/balance semantics, history depth, revision/gap behavior and background timeliness on supported device. Store private results locally; public report only sanitized capability/limitation facts. If route unavailable, owner may explicitly accept a documented statement-only coverage compromise; no constitutional waiver. Actual device account access must use the properly provisioned/signed capture identity and route selected in CUR-044; final iOS installation/update/distribution qualification is separately CUR-053. Route branches are explicit: FinanceKit requires actual authorized API coverage tests; owner-accepted FileOnly requires protected actual statement capture/import and coverage-gap proof while asserting FinanceKit remains disabled. Mark inapplicable automation evidence as unavailable under accepted limitation, not passed or silently skipped. Without an accepted route this gate stays Blocked.
