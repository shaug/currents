## Why

Implement clap CLI with human and versioned JSON responses; Mac client uses same XPC owner and signed approval helper.

## Scope

Implement clap CLI with human and versioned JSON responses; Mac client uses same XPC owner and signed approval helper. Dataset selection explicit; no secrets argv/env, arbitrary SQL or direct concurrent DB open. Independent Linux/Mac verifier opens owner-supplied archive securely for offline replay. Stable exit codes distinguish unavailable/unauthorized/unknown command results.
