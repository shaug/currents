## Why

Extend private seam for ordered native ops/batches on one shared transaction.

## Scope

Extend private seam for ordered native ops/batches on one shared transaction. Each later operation reads prior uncommitted state and refreshed metadata; no intermediate commit. Validate unchanged/idempotent native result cases, keep1000 native batch limit and20000 ops/64 MiB Currents closure limit. Large preview uses encrypted staged manifest reference.
