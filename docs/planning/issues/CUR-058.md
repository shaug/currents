## Why

Build a minimal transfer-only Rust staticlib/XCFramework for aarch64-apple-ios and aarch64-apple-ios-sim.

## Scope

Build a minimal transfer-only Rust staticlib/XCFramework for aarch64-apple-ios and aarch64-apple-ios-sim. Depend on types/protocol canonical encoding, SQLx 0.9/libsqlite3-sys0.37 SQLCipher and private shared cipher initializer, not domain/service/accounting/owner database or dataset keys. SQLCipher Apple crypto provider is source-supported when host/target Apple; sanitize OpenSSL overrides and qualify actual device/simulator separately. Expose bounded C transfer encode/decode/copy/release only under ingress keys; no full-archive restore or financial command authority.
