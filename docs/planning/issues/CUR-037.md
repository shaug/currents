## Why

Build SwiftUI/AppKit navigation, tables, menus, keyboard selection/accessibility and native file import.

## Scope

Build SwiftUI/AppKit navigation, tables, menus, keyboard selection/accessibility and native file import. Position-to-evidence and review/flag journeys always show amount, basis, coverage, freshness/conflict, unknown components. UI is command/query client with no financial math. Lock/offline/rebuild/partial/uncertain states persist beyond toast; financial restoration/QuickLook/Spotlight/clipboard previews disabled by default. Include searchable native register, merchant/category spending and income, account cash flow and monthly trend views with exact basis/date/coverage controls. These are rendered engine reports, not backend-only acceptance.
