## Why

Implement separate secure key/profile initialization before every fresh/pooled native connection touches schema.

## Scope

Implement separate secure key/profile initialization before every fresh/pooled native connection touches schema. Qualify SQLx 0.9.0 + libsqlite3-sys0.37.0 encrypted graph on both targets with correct crypto provider, explicit close, SQL logging disabled. Native schema precedes namespaced Currents objects; attest expected tables/indexes/triggers/migration hashes. No plaintext fallback or unqualified homebrew/system SQLite. Put the reviewed per-connection profile/key initializer in private currents-cipher without owner/domain/native-accounting dependencies so currents-storage and transfer-only iOS library share it; each target still needs independent qualification.
