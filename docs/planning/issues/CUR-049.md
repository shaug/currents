## Why

## Scope

Implement allowlisted diagnostics, secret/private-data scans and hostile parser/archive/wire fuzz harnesses. Protect artifacts, temp, logs, errors, crash reports, UI restoration, Spotlight/QuickLook/clipboard defaults. No telemetry, remote AI, automatic diagnostic upload or source-controlled execution. Security report identifies limits of scans and privileged attacker/swap/crash memory rather than promising perfect confidentiality.
