## Why

Generate C ABI via pinned cbindgen and implement generation-tagged handles, status results, bounded copy/release/cancel/status and trusted key-memory open entry point.

## Scope

Generate C ABI via pinned cbindgen and implement generation-tagged handles, status results, bounded copy/release/cancel/status and trusted key-memory open entry point. C caller must uphold valid pointer/buffer/lifetime obligations; ABI checks null/length/tokens but cannot prove arbitrary pointer validity. catch_unwind contains recoverable panic, invalidates handle and requires reopen/audit. Swift actor off main actor, exactly-once release/idempotent nonthrowing destruction. Persistent encrypted service, not memory-only harness.
