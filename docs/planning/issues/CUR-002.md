- [ ] `cur_002_1`: canonical_vectors: official JCS UTF16 sort/escaping vectors match byte-for-byte; amount1.2300 becomes1.23, negative zero becomes0, no exponent string form
- [ ] `cur_002_2`: strict_bounds: scale19, i128::MIN, coefficient overflow, message above1 MiB, unbounded nesting and unknown financial variants reject without mutation
- [ ] `cur_002_3`: temporal_precision: date-only retains date/no midnight; missing/null/absent/deletion remain distinct; unknown timezone never inferred
- [ ] `cur_002_4`: digest_auth: same body/new session has same digest; changed expected head or one amount changes digest; no bearer bytes serialize into decisions
