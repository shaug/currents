## Why

Implement full-fidelity logical SQLCipher archive and standalone headless verifier, not live file copy or ordinary SQLite backup API.

## Scope

Implement full-fidelity logical SQLCipher archive and standalone headless verifier, not live file copy or ordinary SQLite backup API. Pin coherent read basis and include all retained evidence/history/organization/claims/planning plus policy/unit/calendar definitions. Exclude credentials/capabilities/device keys. Streaming64 GiB/10 million records/1 MiB chunks, destination-space preflight and explicit validated larger override. Storage container reader/writer only validates bounded encrypted record streams. Full export/verify coordinator in service performs semantic/native replay and creates VerifiedFullArchive; no storage-to-service dependency.
