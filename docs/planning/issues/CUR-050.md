## Scope

Complete nightly/weekly property, differential, fuzz/Miri/ASan and fault qualification. Permute arrivals/allocations/revisions, dates/DST/month-end, unit/calendar versions, stale writers and missing receipts. Fault real encrypted storage/exports/generation/key/ABI/mobile boundaries with disk-full/I/O/kill. Miri covers pure supported code not SQLite/XPC; SIGKILL is not physical power loss. Physical power-loss claims require controlled platform qualification and documented limits.
