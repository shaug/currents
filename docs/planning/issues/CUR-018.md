## Why

Implement pinned deterministic position selection and nonoverlapping household aggregation.

## Scope

Implement pinned deterministic position selection and nonoverlapping household aggregation. Most recent compatible source as-of not receipt; equal-time conflict unresolved absent adopted source priority. Expose journal movements/anchored position, pending, coverage/freshness/age/discrepancy and missing inputs. Ownership explicit, brokerage total versus components exclusive. Implement SetDatasetPolicyV1 for effective-dated household ownership/perimeter, source priority, freshness, timezone/reporting currency with previewed downstream invalidation. No silent reinterpretation of prior reports;scope changes require explicit owner decision.
