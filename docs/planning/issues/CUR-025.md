## Why

Implement durable commitments and occurrence identity/version, owner-confirmed timezone with pinned IANA data.

## Scope

Implement durable commitments and occurrence identity/version, owner-confirmed timezone with pinned IANA data. Recurrence daily/weekly/monthly/annual integer interval, monthly clamp/last-day distinct, leap clamp, no default weekend/holiday shift. Horizons1/3/12 calendar months inclusive. Pattern change explicit supersession/remapping; planning module cannot access accounting writer.
