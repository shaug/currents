# FinanceKit entitlement evidence placeholder

This directory intentionally contains **no enabled entitlement plist**.

Before future configuration, separately authorized evidence must establish the
organization account, managed grant, exact bundle/binary association, eligible
distribution and financial-data usage description. Do not invent a bundle ID,
copy another app's grant, enable a capability, sign or submit from this placeholder.
